# NorthStar Logistics

NorthStar is a logistics website and operations dashboard for freight and
shipments across Europe and the United States. The dashboard highlights Greece
as a regional allocation and control hub, with shipment, driver, and regional
allocation data served by an Express backend.

## Run locally

Requires Node.js 20 or newer.

```sh
npm ci
npm test
npm start
```

Open <http://localhost:3000>. The dashboard API is available at
<http://localhost:3000/api/dashboard>, with dedicated shipment and driver
endpoints at `/api/shipments` and `/api/drivers`. The liveness endpoint is
`/health/live`.

Set `PORT` or `HOST` to change the server's listening port or address.

## Dashboard data

The page fetches the dashboard API at load time. The API returns summary
metrics, example shipment records with current ISO timestamps, driver status,
regional allocations, and a generation timestamp. The data is generated by the
server for demonstration purposes; it is not connected to a carrier network,
database, GPS device, or dispatch system.

## Deployment

The source repository is available at
<https://github.com/emailgoodluck-collab/amazon-appdev-2026-hearth>.

This is an Express application, so GitHub Pages cannot host the live site and
API by itself. Deploy the repository to a Node.js web host such as Render,
configure the build command as `npm ci` and the start command as `npm start`,
and let the host provide the `PORT` environment variable. The host URL will
serve both the website and its API.
